# 🎬 Story Scene Studio — 100% Local AI Scene Generator & Trainer

Synthesize authentic, cinematic scene visuals directly from your story scripts on your local Windows PC.
**Zero Google Colab. Zero external API fees. Zero watermarks.**

---

## 🌟 Key Features

1. **100% Local & Free Execution**:
   - Model weights stored securely on `D:/huggingface_cache` (saving C: drive space).
   - Runs cleanly on CPU with optimized PyTorch float32 + DPM++ Multistep Scheduler.
2. **Actual Story Scene Dataset Pipeline**:
   - Built-in multi-genre story scene benchmark dataset (`Epic Fantasy`, `Sci-Fi Cyberpunk`, `Historical Epic`, `Dark Mystery`, `Cosmic Space`, `Maritime Tempest`).
   - Standard HuggingFace `metadata.jsonl` format.
   - Expandable with custom user image-script pairs.
3. **Local LoRA Training & Fine-Tuning**:
   - Pure PyTorch float32 with AdamW.
   - Bypasses broken Colab dependencies (`torchao`, `bitsandbytes`, FP16 unscale errors).
   - Exports lightweight `.safetensors` LoRA adapters to `weights/`.
4. **Cinematic Style Presets & Aspect Ratios**:
   - 9:16 Vertical (YouTube Shorts / TikTok / Reels)
   - 16:9 Landscape (YouTube Standard)
   - 1:1 Square (Instagram / Web)
   - Styles: Cinematic Film (35mm), Epic Fantasy, Sci-Fi Cyberpunk, Dark Mystery, Historical Epic, Anime / Storybook, Nature.
5. **Seamless YouTube Pipeline Integration**:
   - Automatically connected to [`scripts/ai_video_engine.py`](file:///c:/Users/USER/Desktop/Desktop/next/youtubeautomation/scripts/ai_video_engine.py). Every video generated by your YouTube automation pipeline routes each scene to this local generative AI engine!

## 🚀 Quick Start

### 1. Launch Interactive Web UI (Gradio)
```powershell
cd image_gen_model
py app.py
```
Open **`http://localhost:7860`** in your browser:
- **Tab 1: 🎨 Generate Scene Visual**: Type any story scene script, choose a cinematic style & aspect ratio, and click Generate!
- **Tab 2: 🧠 Train Custom Scene LoRA**: Fine-tune the model on your actual scene dataset with live step & loss logs.
- **Tab 3: 📂 Actual Dataset Explorer**: Browse all training scene images, prompts, and genres.

---

### 2. Command-Line Generation (CLI)
```powershell
# Generate a YouTube Shorts vertical scene (9:16)
py local_inference.py --prompt "An ancient stone fortress perched on misty mountain cliffs at sunrise" --style "Epic Fantasy" --aspect "9:16 (Shorts / Reels)"

# Generate a YouTube Standard horizontal scene (16:9)
py local_inference.py --prompt "A futuristic cyberpunk metropolis at night with glowing neon reflections" --style "Sci-Fi Cyberpunk" --aspect "16:9 (YouTube Standard)"

# Generate with a custom trained LoRA adapter
py local_inference.py --prompt "A lone knight in a field of red flowers" --lora weights/story_scene_lora.safetensors
```

---

### 3. Local LoRA Training on Actual Dataset
```powershell
py train_local.py --epochs 3 --lr 0.0001 --rank 4 --samples 5
```
Trained weights are automatically saved to `weights/story_scene_lora.safetensors`.
